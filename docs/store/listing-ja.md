## 説明文

---

単語は知っているのに、聞き取れない。

その理由は、音の変化。「could you」が「クッジュ」に、「it is」が「イリズ」に聞こえるのは、リンキングやフラッピングといった音の変化が起きているから。知らない単語を増やしても、この原因には触れません。

ミミトレは、この「音の変化」を見える化する 3 分集中リスニングアプリです。

■ 60 秒診断で「音が見える」体験
インストール直後の 60 秒診断で、リンキング・リダクション・フラッピングのどれが聞き取れないかがすぐわかります。

■ カラオケ表示で「聞こえた位置」を追う
再生位置に合わせて単語がハイライトされていくカラオケ表示。音の変化がどこで起きているか、文字で追いながら確認できます。

■ リンキング可視化
「took a → トゥッカ」のような音の変化を、IPA と日本語解説付きで表示。チャンクごとの区切り表示で、塊ごとに聞く練習もできます。

■ 音声はすべて AI 生成
レッスン音声は Google Cloud TTS (Neural2) による AI 生成音声です。台本もオリジナルで、既存の音声教材は使用していません。

■ シャドーイング録音と比較再生
レッスン音声 (AI 生成音声) を聞いた後に自分の音声を録音して聞き比べ。録音は端末内にのみ保存され、外部には送信されません。

■ 苦手フレーズ帳と進捗
聞き取れなかった文はワンタップで苦手フレーズ帳へ。連続学習日数・学習時間・ヒートマップで継続を可視化します。

■ 全 12 レッスン収録
カフェ・ホテル・道案内など、実場面の会話とモノローグ。全レッスンの音声付きで、すぐに始められます。

---
【価格について】
すべてのレッスンの基本機能は無料。プレミアムプラン（月額 ¥680 / 年額 ¥4,800）では、完了後の詳細な弱点分析などの拡張機能が利用できます。年額プランには 7 日間の無料トライアルが付きます（無料トライアルは、同じサブスクリプショングループでトライアルを利用したことがない方のみご利用いただけます）。サブスクリプションは自動更新で、解約は App Store のアカウント設定から次回更新日の 24 時間前までに行えます。

## キーワード案

ASC のキーワード欄の上限は「100 文字」ではなく **100 バイト** (日本語 1 文字 = UTF-8 で 3 バイト)。
日本語キーワードを多く入れるとすぐ上限に達するため、**100 バイト以内に収める短縮案**を推奨します。

**短縮案 (94 バイト / 40 文字、区切りを除くキーワード本体は 32 文字、推奨):**

```
英語,リスニング,発音,英会話,英語耳,Toeic,音変化,リンキング,聞き取り
```

**代替案 (70 文字 / 210 バイト、上限超過のため使用不可)：**

```
英語,リスニング,シャドーイング,リスニング力,音変化,リンキング,発音,聞き取り,英会話, Toeic,対策,勉強,英語耳,カラオケ,字幕
```

（「Toeic」は大文字小文字を問われないため TOEIC 対策層にリーチ。）
