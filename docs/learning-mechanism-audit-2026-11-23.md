## 0. エグゼクティブサマリ（問いへの結論）

**問い**: *現在のアプリは、英語リスニングが苦手な人が (1) 自分の弱点を正確に把握でき、(2) その弱点を段階的に克服できる仕組みを提供できているか。*

### 結論（2026-11-23 時点）

1. **(1) 自分の弱点の正確な把握 — 「入口の体験（Aha）はあるが、網羅性・測定精度・経時把握が不足」**
   - `[事実]` 初回 60 秒診断（`src/features/onboarding/diagnostic.ts`）は音変化 8 種（`src/features/lesson/linkingViz.ts`）のうち **3 種（37.5%）** しか測定しておらず、全 12 レッスンで 3 番目に多い `palatalization`（口蓋化: 11 件）や `elision`（脱落: 6 件）を含む 5 種（計 24 注釈 / 全体の 19.2%）が未測定である。
   - `[事実]` 各タイプ 1 問・3 択（偶然正答率 33.3%）のため、タイプ別正答率として学習者の弱点を安定測定できる粒度ではない。
   - `[事実]` `WeakSentence`（`src/features/library/userStore.ts`）は登録日時のみを持ち、正誤履歴・習熟度・復習間隔の概念がない。進捗画面のプレミアム「詳細な弱点分析」も `weakSentences` に含まれる注釈件数を数えるだけで、練習や復習による上達（伸び）を反映しない。
2. **(2) 段階的な克服 — 「単発レッスンの UI 基盤は整ったが、段階練習・適応推薦・間隔反復・再診断のループが未接続」**
   - `[事実]` PR #88〜#91 により、レッスン画面の 4 モード排他（聞く/読む/話す/スクリプト）、`LinkingNoteSheet` → シャドーイング分岐、診断誤答の自動 `weakSentences` 登録、カード内即再生は整備された。
   - `[事実]` 一方で、**診断推薦結果がホーム「今日の1本」へ未接続**（Issue #93）、レッスン横断の **「今日のキーフレーズ」統一提示の欠如**、弱点タイプごとの **「聞き分け→文で確認→シャドーイング」段階ガイド・同タイプ別文への適応転移の欠如**、**忘却曲線に基づく間隔反復と卒業条件の欠如**（Issue #95 関連）、**再診断による前回比較の欠如**が残っており、克服ループが途中で途切れている。
   - `[事実]` スピークバディ・ベンチマークの観点では、さらに **ペイウォールの課金明示コピー（W1: CTA 近傍での終了後金額・自動更新・解約手順・初回限定条件の明示不足、および上部二重余白）** と、**診断から「あなた向けカリキュラム」提示**、**ホームから 1 タップでの復習キュー起動（W4）** が v1.1 の最優先対応領域となる。

### 1.1 診断 (`src/features/onboarding/diagnostic.ts`, `src/app/onboarding.tsx`)

- `[事実]` **問数とカバー率**: `DIAGNOSTIC_QUESTIONS` は固定 **3 問**（`asking-directions` s1 `it is` [`flapping`]、`small-talk-coworker` s2 `going to` [`reduction`]、`weekend-in-kyoto` s0 `took a` [`linking`]）。8 タイプのうち **3 種（37.5%）** しかカバーしておらず、5 種（62.5%）が未測定。
- `[事実]` **タイプ別正答率の測定粒度**: 1 タイプにつき `n = 1`・3 択問題のため、偶然正答率 `33.3%`・タイプ別正答率は `0%` か `100%` の二値しか出ない。`Mimitore-67` Release ビルド実画面（`onboarding?step=result`）でも、結果は `2 / 3 問正解`、各 1 問ごとの `✓ 聞き取れた` / `△ 要強化` 表示にとどまる。
- `[事実]` **可視化と推薦 (`pickRecommendedLesson`) の妥当性**:
  - PR #89 により結果画面はスコアバー＋各問行＋おすすめカード（全問正解時は最初の中級レッスンを返す）へ改善された。
  - 一方、`pickRecommendedLesson` は全問（3 問）の `missedTypes` だけを入力とし、最も多く出現するレッスン 1 本を単発で返すのみ。`diagnostic.ts` の結果・推薦レッスンは `userStore` に保存されず、結果画面を離れると推薦情報が消滅する。
  - `[事実]` `onboarding.tsx:175-185` の `onboarding_completed` ログは `linking_correct/missed`, `reduction_correct/missed`, `flapping_correct/missed` の 3 種のみハードコードしており、他 5 種の計測ができない。
  - `[事実]` 再診断導線は設定画面（`settings.tsx:138-142`）に「聞き取り診断をもう一度行う」が存在するが、過去の診断履歴を保存していないため前回比較ができず、完了しても再び `onboarding_completed` が発火する（再診断イベント区別なし）。

### 1.2 把握 (`src/features/library/userStore.ts`, `src/app/(tabs)/progress.tsx`, `docs/metrics.md`)

- `[事実]` **苦手フレーズ帳 (`WeakSentence`)**: 型定義は `{ lessonId: string; sentenceIndex: number; addedAtMs: number }` のみ（`userStore.ts:45-49`）。復習回数・正誤結果・次回復習日・卒業状態を持たない。
- `[事実]` **進捗画面の弱点分析**: `(tabs)/progress.tsx:54-67` の `weakByType` は `weakSentences` に現在入っている文の `sentence.linking` タイプを単純カウントして水平棒グラフ化している（`isPremium` 限定）。「登録されている数」しか見えず、レッスン完了やシャドーイング・復習で克服してもスコアが伸びたり弱点状態が変化したりしない。
- `[事実]` **習熟度モデルの不在**: アプリ全体（ストア・型定義）にタイプ別・フレーズ別の「習熟度（Mastery）」という概念が存在しない。
- `[事実]` **無料ユーザー側の弱点把握**: 進捗タブの無料側（`progress.tsx:534-552`）は `weakSentences.length` 件数とペイウォール誘導のみ（この無料/プレミアムの境界自体は設計仕様）。

### 1.3 克服 (`src/app/lesson.tsx`, `src/features/lesson/components/ShadowingStage.tsx`, `src/app/(tabs)/phrases.tsx`)

### 2.2 学習科学の理論的根拠（引用・出典つき）

1. **ボトムアップ音声知覚（Connected Speech Decoding）の診断と集中訓練** — *John Field (2008), "Listening in the Language Classroom", Cambridge University Press* `[事実]`
   - Field (2008) は、従来の「内容理解テスト型」リスニング指導では音変化（elision, assimilation, reduction, weak forms, linking 等）による知覚エラーの根本原因に対処できないとし、**連結音声のどの音韻現象でセグメンテーションが失敗しているかを診断し、小規模な知覚集中ドリルを行うプロセス指導**を提唱している。
   - **ミミトレへの適用** `[推測]`: 診断が全 8 種の音変化を網羅し、タイプ別に「聞き分け（知覚）→ 文で確認（意味統合）→ 話す（音韻運動化）」の 3 ステップを回す設計は、Field のボトムアップ処方箋と合致する。
2. **シャドーイングによる音声知覚自動化（Input Effect）** — *Shuhei Kadota (2019), "Shadowing as a Practice in Second Language Acquisition: Connecting Inputs and Outputs", Routledge* `[事実]`
   - Kadota (2019) はシャドーイングの効果を Input / Practice / Output / Monitoring の 4 効果で整理し、音声の即座の再生・模倣反復が音素知覚と語彙分割（word segmentation）を自動化してワーキングメモリ負荷を軽減する（Input Effect）と論じている。
   - **ミミトレへの適用** `[推測]`: 「聞く」段階の音変化理解だけで終わらず、同じ文の「話す（シャドーイング）」まで 1 レッスン内で接続し、その実施回数をタイプ別習熟度へ加算することで音声知覚の自動化を促せる。
3. **検索練習効果（Retrieval Practice / Testing Effect）** — *Roediger & Karpicke (2006), "Test-Enhanced Learning: Taking Memory Tests Improves Long-Term Retention", Psychological Science, 17(3), 249–255* `[事実]`
   - 受動的な反復学習（ST）より、想起テストを伴う学習（T）のほうが 2 日後・1 週間後の遅延保持率を大幅に高めること、また反復再読のみでは「できた気（illusion of competence）」が過大になることを実験的に示した。
   - **ミミトレへの適用** `[推測]`: 復習キューで単に英文を表示して流すのではなく、「まず英文を隠した状態で聞き取る→『聞き取れた / もう一度』を自己想起判定する」フローを設ける根拠となる。
4. **分散学習と漸増間隔（Spacing Effect & Lag Effect）** — *Cepeda et al. (2006), "Distributed practice in verbal recall tasks: A review and quantitative synthesis", Psychological Bulletin, 132(3), 354–380* `[事実]`
   - 184 論文・317 実験・839 評価のメタ分析により、間隔を空けた分散学習が集中学習より長期保持に優れること、および目標保持期間が長いほど最適な学習間隔（ISI）が長くなることを定量的に示した。なお、複数回の復習で間隔を漸増させる方式そのものの優位性については、同論文の知見は暫定的なものにとどまる。
   - **ミミトレへの適用** `[推測]`: 1 日 → 3 日 → 7 日と段階的に間隔を広げ、3 連続成功で「卒業（定着）」とし、失敗時はステージ 0（翌日再出題）へリセットする設計は、保持期間と最適間隔の関係を踏まえた設計仮説として採用する（漸増間隔の優位性が確立した知見であるとは扱わない）。
5. **誤答に基づく動的復習スケジューリング（Half-Life Regression）** — *Settles & Meeder (2016), "A Trainable Spaced Repetition Model for Language Learning", ACL 2016* `[事実]`
   - Duolingo の数百万件の学習トレース分析において、Ebbinghaus の忘却曲線と教師あり機械学習を結合した HLR が従来ベースライン（Leitner 等）比で予測誤差を 45% 超削減したと報告されている。オンライン実験で示された 12% の向上は HLR の構成間の比較に基づく数値であり、Leitner との比較における翌日継続率の差は 0.3% 増にとどまるため、効果を述べる際は比較対象を区別する必要がある。
   - **ミミトレへの適用** `[推測]`: 現行のローカルファースト（サーバなし）方針下では HLR の機械学習自体は不要だが、「誤答・つまずきが記憶半減期（復習間隔）を短縮して優先キューへ浮上させ、成功が間隔を伸ばす」という原理は軽量な純 TS ロジックで端末内に実装可能である。
