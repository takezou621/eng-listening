# ミミトレ UI/UX 競合分析・全画面監査レポート（2026-11-23）

- 対象プロダクト: **ミミトレ（`eng-listening`）** — React Native 0.88 / Expo SDK 58 / iOS 向け英語リスニング学習アプリ
- 監査対象ベースライン: `origin/main`（コミット `2f4a911`、v1.0.0 時点コード＋シミュレータ `Mimitore-67` 実画面検証）
- 準拠基準: [`docs/ui-design-rules.md`](ui-design-rules.md)（P1〜P7、W1〜W8、台帳 D1〜D15）、[`docs/metrics.md`](metrics.md)、[`docs/architecture.md`](architecture.md)
- 記述ルール: 本書では観察・実装・公開資料に基づく確認済み事項を **`[事実]`**、設計上の解釈・効果見込みを **`[推測]`**、公開資料または未実装環境で確認できない事項を **`[未確認]`** として区別して記載する。

## エグゼクティブサマリ

`[事実]` ミミトレは直近の UI 改善群（PR #50, #54, #63〜#67）によって、初期の重大な構造違反（P5 内部情報露出 D1〜D3・D10〜D15、プレイヤー画面の 12 ブロック縦積み D4〜D7、進捗カードの過剰並列 D8）の大部分を解消している。しかし、ベースラインコードの精査および実機同等シミュレータ（`Mimitore-67`）でのライト／ダーク両モード撮影・WCAG コントラスト計算の結果、依然として以下の優先課題が残存していることが判明した。

1. **レッスン再生画面の空間ロス・文字折り返し崩れ・C1/C2 残存課題（高優先）**
   - `Screen.tsx` の `SafeAreaView` がヘッダー表示画面（`lesson.tsx`）でも上部セーフエリアを適用し、ナビゲーションヘッダー直下に **約 60pt の二重余白** が発生している（P3 違反）。
   - `KaraokeLine` の `karaokeSegment` と `karaokeChunk` が二重 `flexWrap: 'wrap'` になっており、実画面上で `Can I get your name?` の **`get your` が縦 2 行に割れてベースラインが崩れる** レイアウト不具合を確認した。
   - 音変化カラー（C1/C2）では、`flapping`（`#C026D3`）の `secondarySurface`（`#EEF2FF`）上コントラストが **4.21:1**（WCAG AA 4.5:1 未達）、`intrusion` がダークモードで暗い赤背景＋下線なしとなり、さらにシート内の記号が丸ドットのみで固有シンボルを持たないため色覚多様性／Android フォールバック時の識別性が弱い。
   - プレイヤー操作系に競合標準の **3 秒巻き戻し** がなく、絵文字ボタン（`⏮ ⏭ 🎙 🔊`）とタブバーの SF Symbols が不統一（P7）、また「音変化解説シート → シャドーイング練習」の 1 タップ分岐がない。
2. **初回診断（60 秒 Aha 体験）結果画面の P4 違反と全問正解時バグ（高優先）**
   - `onboarding.tsx` の結果画面は「フラッピング 1 件」のテキスト行のみで、スコア・達成ゲージ・全問の視覚サマリがない（P4「可視化 > 文章」）。
   - 3/3 全問正解時に `pickRecommendedLesson` が `null` を返すため、**推薦カードと青プライマリ CTA が画面から丸ごと消滅する**。また診断での誤答が苦手フレーズ帳へ自動登録されず、復習ループが断絶している。
3. **進捗画面の可視化精度と WCAG AA 違反色（高優先）**
   - `progress.tsx:106` にハードコードの緑色 `#16A34A`（白背景上 **3.30:1** < 4.5:1）が残存し、`colors.success`（`#15803D`、**5.02:1**）へ未統一。
   - 84 日ヒートマップが単純な `flexWrap` の 1 次元配置で **7 日＝1 週の曜日軸が読めない**。今週 7 日間のストリーク可視化およびプレミアム弱点分析の水平ゲージも欠如している。
4. **ホームの視覚競合・フィルタ冗長性と苦手フレーズの即時復習ループ欠如（中高優先）**
   - ホーム（`index.tsx`）のフィルタチップが 8 個と多く横見切れし、「レベルすべて」が「すべて」と重複しているうえ、選択中チップの青塗りが「今日の 1 本」の CTA と視覚的に競合している。
   - 苦手フレーズ画面（`phrases.tsx`）は音変化バッジがなく、その場で音声再生やシャドーイングへ直接入ることができない。

これらを受け、本書第 3 部では優先度の高い 4 テーマを実装 PR として分割提案し、新権限・課金改定・専用セッション設計を伴う 6 項目を GitHub Issue として分離管理する計画を策定した。

## 第 1 部: 競合サービスの UI/UX 詳細分析（タスク 1）

既存の競合リサーチパッケージ（[`docs/research/competitor-package-2026-11-22/`](research/competitor-package-2026-11-22/INDEX.md) の Duolingo / ELSA Speak / Speak / スピークバディ / abceed / シャドテン）に加え、日本の英語リスニング・学習アプリ市場で主要な **スタディサプリ ENGLISH** と **レシピー（旧 POLYGLOTS）** を追加調査し、5 つの構造軸で詳細分析を行った。

### 1.1 サービス別の構造分析

#### (1) Duolingo（Duolingo, Inc. / App Store 約 78.3 万件・★4.54）
- **オンボーディングとレベル診断**: `[事実]` 起動後「学習動機 → 1 日目標時間（Casual 5 分〜Insane 20 分）→ レベル自己申告 → 任意の適応型プレイスメントテスト」へ進み、アカウント登録は **初回レッスン完了＋1 日ストリーク獲得後** に後置される。プレイスメントテストは通常レッスンと同一の演習画面・進捗バーを使い、「試験」に感じさせない設計を公式ブログが明記している。
- **学習画面（プレイヤー）**: `[事実]` 1 画面 1 タスクを徹底。進捗バー＋残基（上部）、中央の問題エリア、下部固定の単一 CTA（`Check` → 即時フィードバック面＋同一位置の `Continue`）で構成。リスニングはスピーカー再生と亀アイコン（スロー再生）の 2 択、聴覚配慮の「Can't listen now」スキップを備える。正誤は色（緑/赤）＋アイコン（✓/✗）＋効果音＋キャラ反応の多重表現。
- **継続・定着の仕掛け**: `[事実]` ストリーク＋Streak Freeze（損失回避の保険）、XP と週次リーグ、Mistakes（誤答件数を明示した専用復習）と学習パスへの間隔反復埋め込み。一方、完了後に多段の報酬セレモニーが続く点はタップ過多として批判も確認される。
- **課金導線**: `[事実]` 無料でも全言語コースを学習でき、主接点はハート／エネルギー切れやレッスン後の Super 訴求（14 日無料トライアル記載あり、終了 24 時間前解約案内）。
- **ホーム / ライブラリ**: `[事実]` 一本道の縦スクロール「学習パス」で、現在地ノードから 1〜2 タップで開始。
- **ミミトレへの転用**: `[推測]` 診断を試験に見せない簡潔さ、同一位置の下部固定 CTA、週次自動フリーズによる安心設計はそのまま適合する一方、罰則的な中断・多段セレモニーは「3 分体験」と相反するため避けるべき。

#### (2) ELSA Speak（ELSA, Corp. / App Store 約 6.3 万件・★4.57）
- **オンボーディングとレベル診断**: `[事実]` 目標・興味・1 日の目標時間（例 10/15/20 分）・リマインダー時刻を設定して学習パスを生成。発音診断（Assessment Test）はテスト文の読み上げで Pronunciation / Intonation / Fluency を％スコア＋レーダーチャート等で可視化し、弱点スキルを優先提示する。
- **学習画面（プレイヤー）**: `[事実]` 録音→即時に音素単位の色分け（緑＝正確、黄＝やや外れ、赤＝要改善）＋％スコア＋ベル音/ブザー音＋IPA/口形ガイドを返す。赤/黄の単語をタップすると「Practice this word」で単語単体ドリルへ即座に分岐できる。お手本と自分の録音を並べて比較再生する UI を持つ。ただしレビューではボタン過多による初回迷子も指摘される。
- **継続・定着の仕掛け**: `[事実]` Today タブの「Today's Task」（毎日 3 タスク自動生成）と「Your Journey」（現在地〜次レベルの％進捗トラッカー）。ただしストリークは 1 日空けるとリセット・復元不可で厳格型。Word Bank はスコア 80 以下を自動「要復習」に振り分ける。
- **課金導線**: `[事実]` クレジットカード不要で無料開始（Welcome + 各トピック先頭 2 レッスン等）。アカウント作成直後に 1 回限りの 7 日間無料トライアルオファーを出し、Free/Pro/Premium の機能比較表を提示する。
- **ホーム / ライブラリ**: `[事実]` 下部 5 タブ（Today / Learn / Coach / Discover / Progress）。Today タブは「選ばせないホーム」として即開始できる構成。
- **ミミトレへの転用**: `[推測]` 「目標時間→今日の分量表示」「音変化（誤り）箇所タップ→解説＋個別練習への 1 ジェスチャ分岐」「スコア＋ゲージによる診断結果可視化」は非常に有効。

#### (3) Speak（Speakeasy Labs, Inc. / App Store 約 8.1 万件・★4.54）
- **オンボーディングとレベル診断**: `[事実]` 学習目的などのタップ設定＋1 回発話後、目標達成見込み時期を提示。任意の本格レベル診断（60 秒×3 問）は話し方・語彙・文法別の強み／改善点を返すが、レベル外レッスンも自由に選べる。
- **学習画面（プレイヤー）**: `[事実]` 全レベル共通で「インプット（ビデオ）→ スピーキングドリル → ロールプレイ/実践」の 3 段構成。プレイヤーカードは白背景に 1 文＋和訳＋右下/上部ツールに絞り、下部 1 段バー（`あ/A` 字幕切替、巻き戻し、再生/一時停止、早送り、`1x`）と「今は話せない（リスニングのみ）」トグルを備える（`speak/screenshots/04.jpg` 参照）。コースレッスンは基本ハンズフリー自動録音で進行するが、途中で切れる不満対策として自動録音 ON/OFF が求められる。
- **継続・定着の仕掛け**: `[事実]` ストリーク 2.0 では自動適用のフリーズ（最大 2 個）＋セーブチャレンジの救済を採用。スマートレビューが過去の誤りを「コンセプト」単位で自動再出題し、ブックマークした表現の復習導線も持つ。
- **課金導線**: `[事実]` 恒常的な無料プランはなくプレビュー（約 1 レッスン）後に 7 日間無料トライアルへ当たるため、この強硬なゲートが低評価要因として分析されている。
- **ホーム / ライブラリ**: `[事実]` レベル別コース一覧（A1〜C1）＋下部タブの復習・フリートーク導線で到達ステップが短い。
- **ミミトレへの転用**: `[推測]` 「聞く→読む→話す」の段階排他構造、自動録音 ON/OFF トグル、1 文集中カード＋下部 1 段バー、「話せない環境向けの聞くだけ代替」が有効。一方で 1 レッスンでの強制ペイウォールは避けるべき。

#### (4) スピークバディ（SpeakBUDDY Ltd. / App Store 約 6.4 万件・★4.56）
- **オンボーディングとレベル診断**: `[事実]` 目的・レベル入力後に約 10 分のスピーキング形式レベルチェックを実施し、CEFR-J 準拠・5 観点で 10 段階判定と AI カリキュラム（1 日 1 レッスン・5〜15 分）を提案する。提案後もカリキュラムの編集・作り直しが可能。ID 登録は任意。
- **学習画面（プレイヤー）**: `[事実]` 1 レッスンは固定順の 5 モード（単語→リスニング→会話→キーフレーズ/英作文→応用/フリートーク）で進行。会話練習では「会話 1（文字表示あり）→ 会話 2（自分の文を非表示）」と **段階的に支えを外す** 設計を採用。速度調整は設定画面集約型で、着信中断からのスムーズな再開を明記している。
- **継続・定着の仕掛け**: `[事実]` 忘却曲線に基づく「キーフレーズ道場」で習熟度を 5 段階バーと次回復習日数で可視化。固定時刻リマインド、記録メダル・壁紙ミッション等がある。
- **課金導線**: `[事実]` 現行の 3 日間無料トライアルは **「期間終了後に契約しなければ自動課金されない（非自動課金型）」** とストア説明に明記して安心感を作っている。全プラン同一機能で期間（1 ヶ月/12 ヶ月）のみ異なる。
- **ホーム / ライブラリ**: `[事実]` AI バディ（「プロティ」）が最前面で本日のおすすめを提示し、自由選択は「コンテンツ」タブへ分離。
- **ミミトレへの転用**: `[推測]` シャドーイングでの「英文を隠す／表示」による段階的補助外し、非自動/明朗なトライアル説明、着信中断復帰、日本市場向けカードにおける日本語主タイトル階層（`speakbuddy/screenshots/04.jpg`）が参考になる。

#### (5) abceed（Globee Inc. / App Store 約 5.8 万件・★4.75）
- **オンボーディングとレベル診断**: `[事実]` 登録不要で開始し、目的選択→レベルチェック（**問題数を 10 / 15 / 30 問から時間で選択可能**）→予測スコア＆Part 別評価（`abceed/screenshots/04.jpg`: 数値＋横ゲージバー＋総合評価）→1 日の学習時間設定へ進む。
- **学習画面（プレイヤー）**: `[事実]` リスニングプレイヤーは無料プランでも **0.5〜2.0 倍速、区間リピート、3 秒巻き戻し（`abceed/screenshots/03.jpg`）、フレーズ単位移動** を同一画面に搭載。学習中の不明語をワンタップで MY 単語帳へ登録できる。
- **継続・定着の仕掛け**: `[事実]` 学習時間グラフ（無料は直近 7 日、Pro は無制限）、習得率ゲージ、「総復習」（間違えた問題・`?` 問題）へのホーム直行導線。ただし機能追加に伴うホームの過密化と迷子化がレビューで不満として挙げられている。
- **課金導線**: `[事実]` 音声再生・倍速・区間リピート・7 日記録は無料開放し、アプリ内問題演習は数問のお試し後に有料案内が出る体験連動型。3 日間無料トライアル後は自動フリー移行型（ヘルプ明記）や Pro 期間別プラン・単品購入がある。
- **ホーム / ライブラリ**: `[事実]` ホーム常設の予測スコアカード＋「おすすめの問題」「総復習」＋教材タブのカタログ階層（到達約 4 タップ）。
- **ミミトレへの転用**: `[推測]` **3 秒巻き戻し** の即応性、診断結果の「スコア＋横バー＋次アクション」表現、誤答の自動収集→復習キュー化。逆に 4 タップ階層や過密ホームは 12 レッスン規模のミミトレでは避けるべき。

#### (6) スタディサプリ ENGLISH（リクルート / 新日常英会話・TOEIC 対策 / App Store ★約 4.6・数千件超）
- **オンボーディングとレベル診断**: `[事実]` 初回は目的・目安レベル（新日常英会話は Lv.1〜Lv.4）を選択し、「1 回 3 分〜」の手軽さを訴求。チュートリアルを長文で読ませず、実際の学習フローに触れながら理解させる導入。
- **学習画面（プレイヤー）**: `[事実]` 1 レッスン内が「会話理解クイズ → 単語・イディオムチェック → ディクテーション → 会話文チェック → キーフレーズ講義動画（約 2 分）→ リード＆ルックアップ → 瞬間発話プラクティス」の **細かいステップ分割** になっており、1 ステップ 1 タスクでスキマ時間に区切りやすい。音声プレイヤーは倍速・リピート・巻き戻し・スクリプト日英切替を手元 1 タップに配置。
- **継続・定着の仕掛け**: `[事実]` ホーム最上部に「いまここ（直前レッスンの再開ボタン）」「連続学習日数（現在/自己ベスト）」「今日の学習時間・累計グラフ」を配置し、毎日 1 ステップ進める心理的障壁を下げる。
- **課金導線**: `[事実]` 7 日間無料体験（要決済登録・期間内解約で請求なし）。無料未契約時は各コース最初の無料レッスン（FREE）のみ解放されるコンテンツゲート型。App Store 経由と Web 経由で価格差があり、管理画面とアプリが分かれる点は不満レビューとして見られる。
- **ホーム / ライブラリ**: `[事実]` ホーム＝継続ダッシュボード＋「つづきから再開」ワンタップ、レッスンタブ＝ストーリー/レベル別一覧の 2 層。
- **ミミトレへの転用**: `[推測]` **「いまここ」再開動線**、3 分区切りのステップ設計、ホームでの「今日の目標＋連続学習日数」の明示。一方、機能・設定の Web 分散はアプリ完結のミミトレでは避けるべき。

#### (7) レシピー［旧 POLYGLOTS］（ポリグロッツ / App Store ★4.5 前後・累計 2 万件超レビュー）
- **オンボーディングとレベル診断**: `[事実]` 目的・興味ジャンル・1 日の学習時間を選択し、レベル診断（約 10〜12 分、または TOEIC/英検スコア入力）で独自 5 段階の **P レベル**（CEFR 連動）を判定、結果から毎日の専用カリキュラム「My レシピ」を生成する。
- **学習画面（プレイヤー）**: `[事実]` リーディング＋リスニング統合型。スラッシュリーディング（チャンク区切り表示）、ワンタップ辞書、ペースメーカー（WPM 誘導）、ステップ学習（音声→文章→訳→スピーキング）を備える。スラッシュ表示と直訳の併用はミミトレの「読む（チャンク）」モードと同系。
- **継続・定着の仕掛け**: `[事実]` 日別学習時間・スキル別グラフ・カレンダー可視化に加え、記事内で調べた単語が自動蓄積される「My 単語帳」とアプリ起動時の復習クイズで意識せず復習サイクルを回す。
- **課金導線**: `[事実]` フリープランでは英語ニュース閲覧・スラッシュ・ワンタップ辞書・簡易テストまで無料で使え、リスニング音声フル活用・AI 発音チェック・My レシピ・講師サポートを Basic / Standard / Pro（7 日間トライアル付き、終了 24 時間前自動更新停止要）で段階課金する。

## 第 2 部: ミミトレ現行 UI/UX の全画面監査と課題分析（タスク 2）

### 2.1 既知課題の現状検証

#### A. レッスン画面の情報過多（D4〜D7・約 12 ブロック積み上げ）
- `[事実]` PR #63 により、モードは **「聞く / 読む / 話す / スクリプト」の 4 排他セグメント** へ分離され、速度変更・A-B リピート・自動録音設定は `PlaybackToolsSheet`、音変化解説は `LinkingNoteSheet`、凡例は `LegendSheet`、完了サマリは `CompletionSummaryModal` へ段階開示化された（`src/app/lesson.tsx`, `src/features/lesson/components/LessonSheets.tsx`, `src/features/lesson/components/ShadowingStage.tsx`）。よって旧来の 12 ブロック縦積み自体は **解消済み** である。
- `[事実]` しかし実画面（`before-light-lesson-listen.png`, `before-dark-lesson-listen.png`, `before-light-lesson-speak.png`）の精査により、以下の **新たな構造・操作上の課題** を確認した：
  1. **二重トップ余白（P3 課題）**: `lesson.tsx:1124` で `<Screen>` を使用しているが、`Screen.tsx:33` は無条件で `edges={['top', 'bottom', 'left', 'right']}` を指定する。`lesson.tsx` は `<Stack.Screen options={{ headerShown: true }} />` により既にネイティブナビゲーションヘッダーの下に描画されるため、ヘッダー直下に **約 60pt の空領域** が発生し、コンテンツ領域を圧迫している。
  2. **カラオケ風表示の語句縦割れバグ**: `before-light-lesson-listen.png` および `before-dark-lesson-listen.png` で、`Can I get your name?` の **`get` と `your` が上下 2 行に分割され、`Can I` のベースラインとズレる現象** が発生している。原因は `lesson.tsx:1611-1667` の `KaraokeLine` において、`karaokeLine` / `karaokeChunk` / `karaokeSegment` の 3 階層すべてが `flexDirection: 'row', flexWrap: 'wrap'` かつ `alignItems: 'center'` を持つため、横幅計算時に `karaokeSegment`（`get your` の `Pressable`）が先に内部折り返しを起こすためである。
  3. **-3 秒巻き戻しの欠如と絵文字 UI の混在**: `TransportBar`（`lesson.tsx:194-251`）は `[1x] [⏮] [▶ 再生] [⏭]` で構成され、聞き逃した音変化直前へ戻る「-3 秒」操作がない。また再生系ボタンが OS 絵文字（`⏮ ⏭ ▶ ⏸ 🎙 🔊 🔁`）である一方、下部タブバー（`(tabs)/_layout.tsx`）は SF Symbols (`SymbolView`) に統一済みであり、P7（部品統一）の観点で不統一。`ShadowingFooterBar`（`ShadowingStage.tsx:409`）に `12.3s` と英語略称 `s` が混入している点も日本語 UI 表記（`秒`）と不整合。
  4. **解説→発話練習の断絶・完了サマリの目標未連動**: `LinkingNoteSheet` に「この文を話す（シャドーイング）」導線がなく、`CompletionSummaryModal` に「今日の目標（あと何分）」が表示されない。また `npm run lint` 時に `lesson.tsx:978` で `react-hooks/exhaustive-deps` 警告が 1 件残っている。

#### B. 色の課題 C1 / C2（役割分離と非色依存の手がかり）
- `[事実]` PR #50 で `linkingViz.ts` の音変化 8 色から青系が排除され（C1 基盤）、`LINKING_TEXT_DECORATIONS` により下線種別（実線/点線/破線/二重線/イタリック/取り消し線/背景色）が付与された（C2 基盤）。
- `[事実]` しかし WCAG 2.1 相対輝度計算および実機構造の確認により、次の 4 つの残存欠陥が判明した：
  1. **`flapping` のライトモード低コントラスト**: `#C026D3` は白背景（`#FFFFFF`）で `4.71:1` だが、カード・シート内の `secondarySurface`（`#EEF2FF`）上では **`4.21:1`** となり、通常文字の WCAG AA 基準（4.5:1）を下回る（`#A21CAF` に変更すると白上 `6.32:1`・`#EEF2FF` 上 `5.65:1`）。
  2. **`progress.tsx` のハードコード緑の低コントラスト**: `src/app/(tabs)/progress.tsx:106` に `const successColor = scheme === 'dark' ? '#4ADE80' : '#16A34A';` が残存し、`colors.success`（`#15803D` / **5.02:1**）へ置き換え漏れている。`#16A34A` の白背景上コントラストは **`3.30:1`** で WCAG AA 未達。
  3. **`intrusion` のダークモード視認性と非色表現不足**: `LINKING_TEXT_DECORATIONS.intrusion` は `{ backgroundColor: '#B91C1C26' }` のみで下線を持たない。ダークカード（`#151E2E`）に暗い赤半透明背景を敷くと色覚特性を持つユーザーやグレースケールでは他語との境界が判別しづらい。
  4. **Android およびシート内の色依存残存**: `textDecorationStyle`（点線・破線・二重線）はコード注記（`linkingViz.ts:52`）のとおり iOS のみ有効で、Android では実線下線にフォールバックする。また `LinkingNoteSheet` / `LegendSheet` は全 8 種とも同じ 8×8pt の丸ドット（`LessonSheets.tsx:62, 138`）を使っており、色以外で種類を即座に見分ける固有シンボルが欠如している。

#### C. 診断結果画面・進捗画面の可視化（P4「可視化 > 文章」）
- `[事実]` **診断結果画面（`src/app/onboarding.tsx:397-479`、`before-light-onboarding-result.png`）**:
  1. 上部に説明文 2 行、中央カードに「聞き取れなかった音の変化／フラッピング 1件」の文字行があるのみで、**スコア数値・ゲージ・全 3 問の正誤可視化がない**（P4 違反）。
  2. **3/3 全問正解時の空画面バグ**: `pickRecommendedLesson`（`diagnostic.ts:76`）が `missedOrder.length === 0` のとき `null` を返すため、全問正解時は「聞き取れなかった音の変化」カードも「あなたにおすすめのレッスン」カードも両方非表示となり、青プライマリボタンが 0 個の寂しい画面になる。
  3. **診断設問画面（`onboarding.tsx:285-391`）**: 設問の進捗バーがなく、`variant="heading"` 見出しが 1 画面に 2 つ並んでおり（R6.2 抵触リスク）、回答後の解説カードに音変化カラー・下線ラベルのバッジがないためレッスン画面の可視化文法と接続していない。
  4. **苦手フレーズ帳との未接続**: 診断で聞き取れなかった文が `weakSentences` に自動登録されない。
- `[事実]` **進捗画面（`src/app/(tabs)/progress.tsx`、`before-light-progress.png`, `before-dark-progress.png`）**:
  1. **84 日ヒートマップの配列破綻**: `buildHeatmap` の 84 要素を `flexDirection: 'row', flexWrap: 'wrap'` で並べるだけのため、端末幅により 1 行 16 セル×5 行＋4 セルのように折り返され、**「横＝週、縦＝曜日」のカレンダー軸が成立していない**。どの列が今週か、どの日が何曜日か視覚的に判別不能。
  2. **ストリーク・弱点分析の可視化不足**: ストリークカードに今週 7 日の実施ドット（月〜日）がなくテキスト 2 行で説明している。プレミアム弱点分析も件数リストのみで比例バーがない。また 1〜4 カードの高さと余白により、5 カード目の「詳細な弱点分析」が初期画面で下端に切れる。
  3. **`DailyGoalSheet` の重複実装**: `src/components/DailyGoalSheet.tsx` が `BottomSheet.tsx` を使わず独自 `Modal` を実装し、`statusBarTranslucent` 等が未統一。
