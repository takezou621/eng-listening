## 1. 背景と方針

- v1.0（バージョン 1.0、ビルド 5）は App Store 審査中のため、本計画の作業は次版（v1.0.1 / v1.1）向けに機能ブランチ＋ PR の形で用意し、審査提出物へ一切影響させない。`main` へは直接コミットせず、PR のマージも行わない（監督側がレビュー後に判断）。
- 既存の課金（RevenueCat・`paywall.tsx`）・法務文言（`legalContent.ts`・`legal.tsx`）・価格・App Store 情報・`ios/` ネイティブファイルには変更を加えない。
- 全画面で「カラオケ風表示」表記を統一し、「カラオケ」単独表記および内部情報のユーザー露出（P5）をゼロに保つ。

## 2. 競合6社リサーチからの設計指針

| 競合アプリ | 参照ポイント | ミミトレでの取り入れ方 | 避けるべき点 |
|---|---|---|---|
| **Speak** | レッスン内 3 段構成（インプット→ドリル→実践）、ハンズフリー設定 | レッスンを「聞く（カラオケ風表示）→読む（チャンク）→話す（シャドーイング）→スクリプト」の排他モードに分離し、自動録音の ON/OFF 切替を用意 | 画面や機能の足し算で迷子にしない（P1 優先） |
| **シャドテン** | ステップ固定と迷わない導線 | シャドーイングを「① お手本 → ② 録音 → ③ 聞き比べ」の 3 ステップに固定し、次に押すボタンを常に明確化 | 1 回 30 分の重さ（ミミトレの 3 分体験を保つ） |
| **スピークバディ** | 段階的に支えを外す会話設計 | シャドーイング 1 文フォーカス内に「英文を隠す / 表示」トグルを置き、お手本確認後に文字なしで再現できる段階を作る | 長時間の初期テスト（60 秒診断を維持） |

| **ELSA Speak** | 目標から分量を決めるコーチ設計・色+音/記号の二重表現 | 1 日の学習目標（3/5/10/15 分）を設定し、「今日の1本」カードと進捗画面に残り時間・ゲージで連動表示 | 1 画面にボタンを並べすぎること（P2 ≤ 5 を維持） |
| **abceed** | 学習時間設定と達成率の可視化 | 目標達成ゲージと累計/今週の学習量を 1 カード内で可視化 | カタログ型の過密ホーム（12 レッスン規模に合わせる） |

## 3. 作業範囲と詳細設計

### 範囲 A: レッスン画面の再構成（Issue #45 / 台帳 D4〜D7・E18）

1. **ヘッダーとモード排他化（D4 / D5 / P3 / P6）**
   - 固定ヘッダーは `<Stack.Screen>` の「戻る + 日本語タイトル 1 行」と画面上端の 3pt 進捗バーのみに限定し、上部固定パネル（速度 5 ボタン + A-B + メタ）を廃止（D4 解消）。
   - モードは **「聞く / 読む / 話す / スクリプト」** の 4 排他タブ（1 枠セグメントコントロール）で切り替え、従来の縦積み構造（D5）を完全に解消。各モードはその活動に必要な部品のみを表示（R6.3）。
   - 下部固定バーは 1 段構成の `TransportBar`（または `話す` モード専用の `ShadowingFooterBar`）を維持。
2. **段階開示ボトムシート（D6 / D7 / P2）**
   - **再生ツールシート (`PlaybackToolsSheet`)**: 速度変更（`0.7x`〜`1.3x`）、区間リピート（A/B 設定・解除・対象フレーズプレビュー）、お手本後の自動録音 ON/OFF を格納（D7 解消）。下部バーの左端ボタン（`1x` 等）から開く。
   - **音変化解説シート (`LinkingNoteSheet`)**: `聞く` モードで下線・色分けされた語句または下部 1 行ヒントをタップして開く。音変化タイプ・語句・IPA・解説と「この文をもう一度聞く」ボタン・凡例導線を提示（D6 解消）。
   - **音変化の凡例シート (`LegendSheet`)**: `聞く` モードの `? 凡例` から開き、このレッスンに登場する音変化のみの色・線種（C1/C2）と平易な説明を表示。
   - **完了サマリモーダル (`CompletionSummaryModal`)**: レッスン完了時に 1 画面完結のモーダルで提示し、下部再生バーとのプライマリボタン二重表示（P1 違反）を防ぐ。
3. **シャドーイング 1 文フォーカス化（E18）**
   - `話す` モードでは 1 文のみを集中表示（`ShadowingStage`）し、上部に `① お手本 → ② 録音 → ③ 聞き比べ` の 3 ステップを表示。
   - 「英文を隠す / 表示」トグルでスピークバディ型の段階練習を可能に。
   - 録音後は「🔊 お手本」「🎤 自分の声」「🔁 聞き比べ（お手本 → 自分の声を連続再生）」をカード内で即操作でき、下部固定のプライマリボタン（`🎙 お手本 → 録音` / `⏹ 録音停止`）と `前の文` / `次の文` で全 10 文を迷わず往復できる。

### 範囲 B: 進捗と継続の仕組み（Issue #46 残り / D8・E15・E16）

1. **B1: ストリーク救済（E16）**
   - `progressStore.ts` に `computeStreakWithFreeze` を実装し、**週 1 回（月〜日の暦週ごと）まで** 1 日の学習抜けを自動フリーズで保護する（連続 2 日以上の休みや同一週内の 2 回目はリセット）。連続日数自体は実学習日数のみを数え、水増ししない。
   - 当日・前日が休みで前々日に学習していた場合も前日を自動保護し、ユーザーが翌日に戻ってきたときに「昨日のお休みは自動で保護されました」と安心感を伝える。
   - ヒートマップ上で保護された日をアイスブルー + 枠線で表示し、セルタップ時に「フリーズで保護」と表示する。
2. **B2: 1 日の目標設定**
   - `userStore.ts` に `dailyGoalMinutes`（`3 | 5 | 10 | 15` 分、既定 `3` 分）を永続化。
   - 共通ボトムシート `DailyGoalSheet` から進捗画面・設定画面のどちらからでも変更可能にする（ELSA のコーチ式目標設定 + abceed の学習時間設定）。
   - ホームの「今日の1本」カードに `今日 X / Y 分` ピルと達成ゲージを表示し、進捗画面の最上段「今日の目標」カードと連動させる。
   - あわせて進捗画面を §3 準拠（初期ブロック ≤ 5、青プライマリボタン 1 つ、独立セクション見出し 0、1 カード 1 指標）に整理し、台帳 D8 を解消する。
3. **B3: ライブラリのタイトル階層（E15）**
   - **判断: 日本語タイトル (`titleJa`) を主 (`heading`)、英語タイトル (`title`) を副 (`caption`, `muted`) に統一する。**
   - **競合スクリーンショット比較による根拠**:
     - `elsa/screenshots/03.jpg`、`abceed/screenshots/05.jpg`、`speakbuddy/screenshots/04.jpg`、`duolingo/screenshots/01.jpg`、`speak/screenshots/02.jpg` では、日本人学習者がレッスンを選ぶ一覧カードで日本語タイトルを主見出しに置き、英語タイトルは補助情報にしている。英語主見出しは中上級・TOEIC 特化のシャドテンに限られる。
     - ミミトレ内部でもホームの「今日の1本」カードとレッスン画面のヘッダーが既に日本語主見出しであり、一覧カードだけが英語主見出しだった不整合を解消することで認知負荷を下げる。
   - ライブラリカード、苦手フレーズ帳のレッスン出典名、診断結果のおすすめカードをすべて日本語主へ統一する。

### 範囲 C: 全体のポリッシュ（§3 自己点検）

- 全画面（ライブラリ / 苦手フレーズ / 進捗 / 設定 / 診断 / レッスン / ペイウォール / 法的情報）を [UI デザインルール §3](../ui-design-rules.md) で数値点検し、結果を `docs/research/ui-polish-audit-2026-11-22.md` に記録する。
- セマンティックカラー（`success` / `danger` / `warning` / `favorite`）を `src/theme/colors.ts` に集約し、ダークモードでのコントラストを統一。
- 診断画面（`onboarding.tsx`）の回答後に上部再生ボタンをセカンダリ枠線化し、下部フッターとプライマリボタンが重複する P1 違反を修正。
- 設定画面・空状態・8pt グリッド余白の不統一を解消。
