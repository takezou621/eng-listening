## 2. 本 PR（範囲 C）で実施した改善

1. **セマンティック状態色のテーマ集約（`src/theme/colors.ts`）**
   - ハードコードされていた `#16A34A` / `#DC2626` / `#F59E0B` 等を `colors.success` / `colors.danger` / `colors.warning` / `colors.favorite` としてライト・ダークそれぞれに適切な明度で定義し、ダークモード視認性（W7）を底上げしました。
2. **初回診断画面の P1 違反修正（`src/app/onboarding.tsx`）**
   - 回答後（`answered !== null`）に画面上部の再生ボタンと下部フッター（`次の問題へ` / `結果を見る`）の両方が青フィルになりプライマリボタンが 2 つ並んでいた状態を修正し、回答後の上部ボタンをセカンダリ枠線ボタン（`↻ もう一度再生する`）へ切り替えるとともに、重複していた 2 箇所の「もう一度再生する」テキストリンクを整理しました。
3. **空状態・余白（8pt グリッド）・リスト階層の統一（`index.tsx`, `phrases.tsx`, `progress.tsx`, `settings.tsx`）**
   - ライブラリ（フィルタ結果 0 件）と苦手フレーズ（登録 0 件）の空状態を同一カード構造＋セカンダリ枠線 CTA に統一。
   - 進捗画面の統計 5 枚を 2×2 サマリへ統合し、ブロック数を 5 以下に収め、プライマリボタンを 1 つ（`今日の1本をはじめる`）に整理（D8/P1/R6.2 解消）。
   - 設定画面のグループ見出しを `caption` 太字へ揃え、各グループ最終行の不要な下線を除去し、最下部にタブバーとの余白を確保しました。
