## 競合5アプリの型

1. **Duolingo** — 極端な最小主義。1画面=1タスク。上部は進捗バーとハートのみ、大きな選択肢カード、CTAは1つ。
2. **ELSA Speak** — 分析はダッシュボード型だが「1カード=1指標」（ピッチ波形/ペースゲージ/スコア円）。文章でなく可視化で伝える。ドリルは1音素1画面。
3. **Speak** — 会話画面は吹き出し1つ（英＋訳）＋キャラクター＋ヒントカード＋大きなマイクボタン1つ。操作系は端のアイコンのみ。1ターンに集中。
4. **スピークバディ** — キャラ＋吹き出し2つ＋録音ボタン1つ。装飾最小、会話だけが主役。
5. **abceed** — ライブラリは書籍表紙グリッド（"探す"画面なので密度が許容される）。ただしAI会話の学習画面は1ターン集中（自分の回答の単語色分け＋お手本を1カードに集約）。

## 共通原則

- 学習画面は「1画面1タスク」。今やること以外は出さない
- 詳細は段階開示（タップ/完了後にカードやシートで出す）
- 速度・リピート等の設定系はサブメニューや文脈表示に格納。主要アクションは大きなボタン1つ
- フィードバックは文章でなくスコア・ゲージ・色で可視化
- 技術情報・生成メタ情報はユーザー画面に出さない

## ミミトレへの改善提案（v1.1 UI パス、優先順）

1. **技術ヘッダーの除去**: プレイヤー上部の「パイプライン生成レッスン (Google Cloud TTS Neural2 + faster-whisper)」「config 1b1725b9」をユーザー画面から外す（設定の情報画面などへ）。最も「作りかけ」に見える要素。
2. **プレイヤーの2層化**: 既定はカラオケ文＋再生＋進捗のみ。速度・A-Bリピート・凡例は下部の展開シート（ツール）に格納。
3. **モードの完全分離**: カラオケ/チャンクのタブにシャドーイングとスクリプトも加え、縦積みをやめる（各モードが1画面を専有）。
4. **リンキング解説をボトムシート化**: ハイライト語句タップで IPA＋解説をシート表示（Speak のヒントカード型）。常設カードは廃止。
5. **凡例は初回チュートリアル＋ヘルプに移動**: 4色凡例の常設をやめる。

診断・ライブラリは現状維持でよい。
