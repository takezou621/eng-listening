# シャドテン (PROGRIT Inc. / 評価数 約3,500)
App Store: metadata.json 参照。スクリーンショット: screenshots/。公式: https://www.shadoten.com/

## ポジション
シャドーイング特化 + プロの人間による添削。月額21,780円の高価格モデル。ミミトレの「シャドーイング」機能の最も近い競合。

## UI/UX の要点
- トレーニングは7ステップに完全システム化: ①レベルチェック ②教材選び ③やり方を動画で確認 ④自主トレ ⑤録音を提出 ⑥添削返信（24時間以内） ⑦指摘の修正トレーニング（添削サイクルは4回）
- 自主トレの順序が固定: リスニング → 内容理解 → オーバーラッピング → シャドーイング。「何をどの順でやるか」をユーザーが考えなくてよい
- 教材選びは WPM（1分あたりの単語数）でレベル出しする客観指標
- 録音→提出→フィードバック→反復、のループがアプリ内で完結

## ミミトレが借りるべき点
- 手順の固定化とステップ表示: ミミトレのシャドーイングも「お手本を聞く→一緒に言う→録音→聞き比べ」をステップとして明示すると迷いが消える（Issue #45 の1文フォーカス化とセットで）
- 「やり方を最初に短く見せる」導入（動画の代わりに1画面の図解でも可）
- WPM のような客観指標で教材の難しさを示す（ミミトレは速度変更で吸収しているが、レッスンカードへの指標表示は検討余地）

## 避けるべき点
- 1回30分の前提はミミトレの「3分」と両立しない。手順の明快さだけを借り、分量は3分に収める
- 人間の添削はミミトレの価格帯では不可能。録音の自己比較（お手本と自分の波形/再生の並置）で代替する
